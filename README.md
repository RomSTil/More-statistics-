# Обновление v0.2: Разделение архитектуры и кроссплатформенность с Flet



В версии v0.2 проекта была реализована модульная архитектура с разделением на:

* Серверную часть: отвечает за обработку данныx.

* Клиентскую (графическую) часть: предоставляет пользовательский интерфейс.

С помощью Flet можно собирать приложения в рахных форматах что делает его удобным решением для кроссплатформенной разработки.

В ходе работы над проектом возникла необходимость упростить процесс передачи данных на мобильные устройства. Если пользователь захочет использовать мобильную версию приложения, парсинг данных и их скачивание на телефон становятся неудобными и трудоемкими.  

Для решения этой проблемы была предложена идея передачи данных с использованием ссылки. Таким образом, создается сервер, который работает в локальной сети, и через специальную ссылку можно передавать данные, такие как баллы учеников, прямо в приложение на телефоне. Это значительно упрощает процесс и позволяет избежать необходимости загрузки файлов или парсинга на мобильном устройстве.

Преимущества:

>Удобство и скорость передачи данных без необходимости скачивать файлы.

>Работает внутри локальной сети, что повышает безопасность передачи.

>Легкость в реализации и использовании для конечного пользователя.
